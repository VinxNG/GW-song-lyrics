# GW Song Lyrics — 9 August 2026

This folder is ready for GitHub Pages.

## Files
- `index.html` — complete mobile-friendly song lyrics webpage

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will display the public webpage address after deployment.

The webpage is self-contained: the landing poster, logo and watermarks are embedded in `index.html`.
